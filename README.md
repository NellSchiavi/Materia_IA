## Sobre a lista de exercícios Python

Notebook com a resolução dos 50 exercícios propostos, organizados de forma
sequencial. Cada exercício contém o enunciado em célula de texto, a solução
comentada em célula de código e a justificativa das escolhas feitas.

**Conteúdos abordados:**

- Entrada e saída de dados, conversão de tipos e f-strings
- Estruturas condicionais (`if` / `elif` / `else`)
- Laços de repetição (`for` e `while`)
- Estruturas de dados: listas, dicionários, conjuntos e matrizes
- Funções, parâmetros, retorno e recursão
- Manipulação de strings e fatiamento
- Algoritmos de ordenação (Bubble Sort e Insertion Sort) e busca binária
- Criptografia com cifra de César
- Estatística básica: média, variância e desvio padrão
- Visualização de dados com `matplotlib`

**Bibliotecas utilizadas:** `math`, `random`, `string`, `statistics`,
`collections`, `matplotlib`

## Como executar

Os notebooks foram desenvolvidos no Google Colab e podem ser abertos
diretamente pelo botão *Open in Colab* no topo de cada arquivo.

Alguns exercícios reaproveitam funções definidas em células anteriores,
portanto recomenda-se executar o notebook na ordem, usando
*Ambiente de execução → Executar tudo*.

Vários exercícios solicitam dados via `input()` e aguardam digitação
durante a execução.
